Story snippets can follow the controls. Each story's snippet now comes with a template, and the preview fills it with the current args, like `@storybook/react`. Turn it on with `features.experimentalLiveServerSnippets: true`. This needs Storybook `11.0.0-beta.3` or later, so the `storybook` peer range is now `^11.0.0-beta.3 || ^11.0.0`.
